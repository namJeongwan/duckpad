## App behavior

- Text and margin context menus receive localized labels through a narrow
  Scintilla delegate callback. The bridge maps pinned command tags to stable
  identifiers. Targets, actions, separators, and enabled states remain native.
  The regression dispatches actual Undo/Redo and checks read-only Copy versus
  disabled mutation commands.
- New untitled documents and restored collision copies carry optional generated
  title metadata. Presentation localizes only that metadata; saved filenames,
  raw persisted titles, document identities, and text remain intact. Saving or
  changing a file location clears generated-title metadata. Old archives without
  the new optional field remain readable. Ambiguous legacy titles are preserved
  rather than inferred from arbitrary `new N` or `(restored)` filename text.
- Generated-title metadata survives editor-group snapshots, search captures and
  results, and document comparison. Live language changes update labels, window
  titles, comparison choices and captions, and tab widths. Duplicate comparison
  names are distinguished using the displayed names and paths/identifiers.
- Inspector static labels, complete help sentences, colored status labels,
  dynamic page/screen captions, and built-in ImGui table/docking menus use the
  host localization bundle. All **310** reviewed engine keys are included in the
  normal **1,139 strings + four plural entries** for each supported language.
  Protocol field names, user terminal text, and technical identifiers remain
  unchanged. The unrelated upstream ImGui demonstration is no longer opened by
  default.
- Inspector fonts use macOS system files without bundling a new font dependency.
  Korean uses Apple SD Gothic Neo; Japanese uses Hiragino Sans; Simplified Chinese
  uses the compatible STHeiti TrueType collection. Modern PingFangUI outlines are
  unsupported by the embedded stb font loader: the first visual verification
  caught replacement glyphs, and a new actual-atlas glyph check failed on
  `zh-Hans` U+7EC8 before the font correction and passed afterward.
- Changing language recreates open Inspector views and font atlases together.
  The terminal surface, session, and inspector window/frame remain intact.

The engine patch and key inventory are reproducible inputs of
[build_ghostty.sh](../../../scripts/build_ghostty.sh), including its cache key.
Vendor integration changes are documented in the Ghostty and Scintilla
`PROVENANCE.md` files. The generated framework is ignored, not committed.

## Plugins and catalog

Clipboard History searches images using the current interface's `Image` label,
including partial matches, while retaining the English `image` alias and existing
text/path searches. A language change reruns the current query. Persistence and
the Rust state format do not change. Its **31** keys must be present with matching
format arguments in all eight packaged locale tables before native compilation.

The catalog now supplies English, Korean, Japanese, Simplified Chinese, German,
French, Italian, and Brazilian Portuguese descriptions for Clipboard History and
PlantUML. The catalog validator rejects a missing supported description. No
PlantUML binary change is needed for catalog metadata.

The enhanced plugin UI regression fails the downloaded, unmodified 0.3.2 module
at the Korean image query. The rebuilt local module passes all eight localized
queries through the native ABI and actual AppKit panel. A focused engine test
also covers unnamed images, partial queries, negative matches, English aliases,
ordinary text, and persisted history without accessing the real clipboard.

## Validation

- Related Swift suites: **440 test functions passed**, covering presentation,
  native editing, domain/session metadata, search/comparison, recovery, editor
  groups, format Undo/Redo, and asynchronous save behavior. Live group-title and
  Inspector locale-change regressions are additionally run separately because
  they intentionally mutate the process-wide language. Both final live tests
  passed with the corrected Chinese font: **442 distinct Swift functions** in
  total across these runs.
- The new targeted regression run passed seven functions, including actual
  English → Korean → Japanese → Chinese → English Inspector replacement,
  generated-title group labels/widths with unchanged workspace metadata,
  search/comparison metadata, old-archive compatibility, filename preservation,
  and localized-name collisions.
- `python3 scripts/verify_localizations.py`: all eight host catalogs pass key,
  plural, placeholder, complete Inspector printf-specifier, and hidden widget-ID
  validation.
- `bash scripts/test_inspector_localization.sh`: actual native Metal rendering
  passes in all eight languages, including built-in docking-menu requests and
  actual font-atlas glyph presence for a representative character per locale
  (not exhaustive coverage of every translation character). All eight baseline PNG snapshots were
  visually inspected. Every tooltip and inspector interaction was not manually
  exercised in every language; long dock labels retain ImGui's native ellipsis.
- Clipboard History: locale gate, focused localized-image search test, native
  module build, and enhanced full native ABI/UI smoke pass. The baseline smoke
  fails on the old public module as expected. The full smoke uses a dedicated
  pasteboard and temporary storage.
- Plugin catalog: seven tests, repository validation, and index-freshness checks
  pass. The added coverage test fails for each of the six newly required locales
  under the original validator, then passes with the corrected validator.
- `git diff --check` passes in all three worktrees. Independent source review
  found no remaining Blocker/Major issue; final font and test refinements are
  included in the follow-up review.

The related broad run exposed an existing fixed-sleep debounce test that asserted
before the main actor delivered its callback under native UI load. It now polls
for bounded eventual delivery while retaining the exact count and option
assertions. This is a functional delivery test, not a latency/performance gate.

This phase builds the native engine, app/test targets, and plugin module. It does
not claim a universal release package, notarization, Intel hardware execution, or
a published app/plugin binary update. Catalog translations become available
when the catalog PR reaches main. The Clipboard History fix needs a new plugin
release when publication is requested; its public 0.3.2 archive must stay immutable.
