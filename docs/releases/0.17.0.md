# Duckpad 0.17.0

Duckpad now offers native automatic completion from the first committed character, with current-document words and language keywords available without installing a language server. The compact popup follows the editor theme, refreshes while deleting, and stays quiet at empty prefixes, inside strings/comments and while declaring new class names.

## Language support

Optional Python, Ruby/Rails and Rust support packages share a common LSP client. Install the corresponding **0.1.0 language plugin** from Plugins Admin → Available Plugins, or download its separate ZIP asset from this release and use Install Plugin. The packages are not bundled into the app.

Python defaults to basedpyright and also supports Pyright and ty. Ruby uses Ruby LSP, and Rust uses rust-analyzer. Server binaries and project dependencies remain separately installed tools; Duckpad does not download them automatically. Configure server and interpreter choices in Preferences → Language Support for all defaults, the current workspace or a selected folder. Recovered workspaces keep independent choices, even when two windows open the same project.

Python method-name completion uses actual server results. In a class, basedpyright and Pyright suggest methods such as `__init__` and `__repr__` after `def __`. Inserted method bodies retain indentation and line endings; completion and additional imports form one Undo operation. The tested ty version does not return candidates in that method-name slot.

Plugin definitions are signed and checked again by the authenticated helper before server launch. Disabling or removing a provider withdraws its registrations and pending results. Language servers run through the existing unsandboxed helper; this capability is not a filesystem sandbox.

## File reload

Reload from Disk now explains missing-file, permission and I/O failures and provides a working Retry action. Keep Editing acknowledges the observed external version or outage without hiding later changes or new outages. Unsaved edits retain the existing revision and discard-confirmation safeguards.

## Compatibility and installation

The app and all three helpers are **0.17.0 (70)**, upgrading **0.16.1 (69)**. Requires macOS 13 or later. The universal build includes Apple Silicon and Intel. Existing documents, recovery data, native plugin ABI and settings remain compatible; legacy Python settings migrate to the common workspace-aware language settings. Language plugins require host API 1.5.0 and keep their separate version 0.1.0.

Download `Duckpad-0.17.0-universal.dmg` or `Duckpad-0.17.0-universal.zip` and verify against `SHA256SUMS.txt`. Homebrew installations can run `brew update` followed by `brew upgrade --cask namjeongwan/duckpad/duckpad` after the tap update. Existing installations can use Check for Updates after the signed feed is published.

## Validation and limits

Before release preparation, 164 focused Swift test functions passed, covering native committed input/IME/context, atomic edits and Undo, language-provider authority/lifecycle, independent workspace settings and file-reload regressions. Actual basedpyright, Pyright, ty, Ruby LSP and rust-analyzer integrations passed. Packaged native checks exercised signed installation, member completion, first-character/deletion behavior, method-stub Tab/Undo/Redo and reload controls. All eight localization resources parse with identical key sets; English/Korean preferences and dark/light completion panels were visually inspected.

Stable publication requires a universal build from the merged release source, matching app/helper versions, bundle/resource/XPC/signature checks, isolated packaged application and localization smoke, archive integrity and uploaded asset hash verification. Any skipped smoke checks are reported separately.

Intel hardware execution, macOS 13 runtime, a full Rails application, six locale preference windows, physical Korean keyboard interaction and full repository suite completion are not claimed. Server indexing and third-party type information affect semantic results. The distribution is ad-hoc signed, without Developer ID signing or Apple notarization.
