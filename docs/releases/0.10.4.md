# Duckpad 0.10.4

This patch improves large-file editing across JSON, JavaScript, CSS, XML, Unicode text and tab-heavy documents.

- Incremental UTF-8, UTF-16 and tab-column indexes reduce repeated coordinate scans after edits.
- Faster measured character advances, tab layout, wrapping and Unicode segmentation preserve existing text geometry and rendering.
- Large JavaScript, CSS and XML syntax requests run on verified worker snapshots. Fold updates and deferred Collapse All yield between short batches so editing can continue.
- An extreme-metric tab calculation no longer overflows its integer range.

App and helpers: **0.10.4 (56)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel. Documents, sessions, settings, Undo/Redo and the native plugin ABI remain compatible. Large-file syntax highlighting is eventually consistent while background work completes.

## Installation

Download `Duckpad-0.10.4-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.10.4-universal.zip`. Verify the downloads against `SHA256SUMS.txt`. The signed Sparkle update feed is published after the release archive is uploaded.

## Validation and limitations

On the development Apple M4 Pro, a full Release run of 14 approximately 9.18 MB fixtures passed all 10,752 input events with a 42.70 ms maximum. First committed input took at most approximately 41.79 ms, including native input queries, status, drawing and layer flush. File loading precedes these measurements. The originally reported JSON reached a 39.49 ms maximum.

Additional pending-style, recolouring/folding and cold-position runs brought the final accepted groups to 33 runs and 15,312 input events; their largest gate, including main-loop stalls, was 46.68 ms. Earlier failed runs remain in the [performance evidence](https://github.com/namJeongwan/duckpad/blob/v0.10.4/docs/wiki/long-line-performance-gates.json). These are fixture-specific measurements, not a hard real-time guarantee for arbitrary files, machines or external load.

Native correctness tests passed approximately 2.83 million checks, including exact coordinates, Unicode and malformed bytes, representations, lexer results, tab boundaries and Undo/Redo. ASan/UBSan passed with the eight changed native implementation units instrumented, and all 144 baseline geometry cases matched. The 330 focused editor adapter tests passed serially. Whole-package Swift test compilation remains blocked by an existing concurrency error in `MenuPresentationSpy.swift`.

The default build is ad-hoc signed, without Developer ID signing or Apple notarization. Physical Intel hardware, macOS 13 and live Korean IME were not tested for this patch. Interactive system-picker smoke checks are skipped unless explicitly enabled.
