# Duckpad 0.14.0

Search file contents across open documents and directories, replace matches without automatically saving files, and find files by name with two taps of Shift.

- Use Command-Shift-F / Command-Shift-R for Find / Replace in Files. Compact match rows show filenames and line numbers above a resizable, syntax-coloured context preview. Search supports case matching, whole words, Normal / Extended / Regex modes, and filename masks.
- Choose All, Open Documents, Workspace, or Folder in both project search and filename search. Open buffers take precedence over duplicate disk paths. A separately chosen Folder does not become a workspace root.
- Tap Shift twice to search filenames and paths. Open a result normally or in a right split. Unsaved tabs are included in Open Documents and All.
- Replace one selected match or confirm Replace All after a completed, nontruncated search. Changes remain unsaved, preserve per-document Undo, and are checked against the searched revision and file identity. Changed, read-only, composing, cancelled and over-limit targets are reported.
- Folder discovery uses bundled ripgrep 15.1.0 and respects its ignore rules; Duckpad's existing matcher determines final text matches and replacement semantics. No separate ripgrep installation is required.
- Classic Command-F / Command-H retain the familiar Notepad++ style Find / Replace dialog. Shared colours, controls and input alignment connect the search windows, while Korean marked-text edits update search without a trailing space or backspace.
- Keep long highlighted search results on one row with proper ellipsis truncation. Reaching the bounded filename-discovery budget returns explicitly incomplete results instead of reporting an unavailable folder; incomplete results cannot trigger Replace All.
- Remove the repository's unused deployment/telemetry configuration. This does not remove the application's existing usage-statistics controls.

App and helpers: **0.14.0 (62)**, upgrading **0.13.0 (61)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel. Existing settings, recovery data, encodings and native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.14.0-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.14.0-universal.zip`. Verify downloads against `SHA256SUMS.txt`.

## Validation and limitations

The implementation passed 332 distinct related test functions before subsequent focused follow-ups. The final scope and file-access follow-up passed 68 distinct functions, and the final filename-header follow-up passed 15. The final pre-release discovery-budget and row-layout follow-up passed 30 distinct functions across eight suites. These sets overlap and are not an aggregate test count. They cover replacement Undo and stale targets, scope precedence, cancellation, root/symlink changes, split navigation, Korean IME updates and control state. All eight localization catalogs pass key and format validation (1,180 strings and four plural entries). Layout snapshots cover eight languages; selected English dark and Korean light views were visually inspected. Packaged artifact verification and isolated launch smoke results are recorded with the published release.

Filename indexing is bounded to 20,000 entries and displays up to 100 results. Project search displays up to 5,000 match rows and reports truncation. Replace All is disabled for incomplete or truncated results; folder replacement prepares at most 200 files per operation. Undo is per document, not a single transaction across files. Context previews are bounded excerpts, not a full before/after diff. Gold match-row highlights are provided for Normal literal searches; exact context highlighting is available when the native preview can be prepared. Folder content search does not decode every legacy encoding supported by manually opened documents.

The full repository test suite, physical Korean keyboard interaction, full manual inspection in all eight languages, Intel hardware and macOS 13 were not exercised. The native Save panel automation is skipped by the isolated smoke script. No universal sub-50-ms search latency guarantee is made.

The distribution is ad-hoc signed, without Developer ID signing or Apple notarization. Bundled ripgrep attribution and dependency notices are included in the app.
