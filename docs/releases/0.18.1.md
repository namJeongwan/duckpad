# Duckpad 0.18.1

Markdown Live editing now places the caret on the clicked list item and moves
through rendered rows one at a time with Up/Down. Previously, lists below a
rendered table could reject clicks on some items or jump over every other item.
The table's 12px top/bottom margins appeared on screen but were missing from
CodeMirror's measured height, leaving following text coordinates 24px out of sync.

Block previews now contain their existing vertical margins in a measured wrapper.
This preserves their spacing while aligning text hit testing and cursor movement.
The same handling covers tables, standalone images, rules, code headers and inline
Mermaid diagrams. Inline images retain their existing DOM shape. The fix does not
modify Markdown bytes, dirty state, file formats or the native Undo history.

## Compatibility and installation

The app and all three helpers are **0.18.1 (72)**, upgrading **0.18.0 (71)**.
Requires macOS 13 or later; the universal app includes Apple Silicon and Intel.
Host API **1.6.0**, native ABI v1 and all independently released plugin versions
remain unchanged. No runtime dependencies were added or upgraded.

Download `Duckpad-0.18.1-universal.dmg` or `Duckpad-0.18.1-universal.zip` and verify
against `SHA256SUMS.txt`. After the tap update, Homebrew installations can run:

```sh
brew update
brew upgrade --cask --greedy namjeongwan/duckpad/duckpad
```

Existing installations can use **Check for Updates** after the signed feed is
published. The distribution is ad-hoc signed, without Developer ID signing or
Apple notarization.

## Validation and limits

The unchanged baseline fails the real-browser regression with the same 24px
coordinate offset. The fix passed **27 Node tests**, **24 Chrome viewport/zoom
cases** and **12 native WebKit input cases**. Tests cover Korean text and inline
code in five-item lists after tables, images, rules, code, Mermaid and mixed
blocks. They verify the measured height map, every item's click target, Up/Down
navigation, unchanged source and no document-edit messages during navigation.

In addition, **28 existing CodeMirror integration cases** passed in Release
configuration, covering table controls, edits, Undo/Redo, save/recovery, modes,
shared panes and simulated Korean composition. The opt-in typing/drag benchmark
was skipped.

The universal release app passed bundle/signature verification and the packaged Markdown
smoke, including table controls, stable cell widths, Source/Live switching,
Mermaid/math, links and source/revision preservation. The release app was rebuilt from merged main commit
`5b3749dbc75d1d64e5eaf13fe93be4b05d72dbea`; app/helper versions, both
architectures, packaged fixed resources, all eight UI locales, default app
smokes and DMG/ZIP integrity were verified before publication. Tests use isolated profiles or
windows; the reported original document was only read.

Intel hardware execution, macOS 13 runtime, physical Korean IME interaction and a
full repository test-suite run are not claimed. Optional native Save-panel
automation is not part of this patch validation. See the
[Markdown verification instructions](../wiki/40-markdown-preview.md#block-layout-and-caret-regression-2026-11-13).
