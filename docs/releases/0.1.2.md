# Duckpad 0.1.2

Better responsiveness when editing long Unicode lines.

## Fixes

- Reuse measured Unicode text segments instead of repeatedly shaping identical segments. This particularly improves long lines of repeated Korean text, emoji, and combining characters. Font shaping and zoom behavior are preserved.
- Show the affected path and recovery guidance when a file is missing or access has expired.

In the same 5 MiB repeated-Korean-line test, median typing improved from about 435 ms to 23 ms and Backspace from 443 ms to 28 ms on Apple Silicon. Results depend on file contents; very long lines can still cost more to render than shorter lines.

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.1.2-universal.dmg` and drag Duckpad to Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also available.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

Intel execution is tested through Rosetta on an Apple Silicon Mac; physical Intel hardware testing is not included.
