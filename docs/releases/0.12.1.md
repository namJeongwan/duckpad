# Duckpad 0.12.1

Duckpad adds usage statistics to help prioritize editor and plugin improvements.

- Statistics are enabled by default. A one-time, nonmodal notice links to Privacy settings, where sharing can be turned off at any time. An existing explicit opt-out stays off.
- Reports cover first observed runs, version changes, daily activity, editing languages, feature and plugin usage, and operation outcomes. First-run and version-change markers are saved only after successful delivery, so interrupted or rejected transmissions remain eligible on the next launch.
- Document contents, file names and paths, searches, terminal commands, raw errors, and persistent device identifiers are excluded. Private plugin IDs and unrecognized languages are grouped as `other`.
- Counters are aggregated in memory and sent in bounded background batches. Disabling sharing cancels transmission and clears pending statistics and the local transmission log. Failed delivery does not interrupt editing or delay app termination.
- Privacy settings and the first-run notice are localized in all eight supported languages. The transmission log lets you inspect the five most recent batches in the current session.

App and helpers: **0.12.1 (59)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel. Existing document formats, recovery, settings and native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.12.1-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.12.1-universal.zip`. Verify downloads against `SHA256SUMS.txt`. The signed Sparkle update feed is published after the release archive is uploaded.

## Privacy and measurement limits

Statistics are sent through Cloudflare to Duckpad's self-hosted statistics server. The ingestion proxy strips connection-IP, cookie and location headers before forwarding events to the analytics application; network providers still process connection IP addresses. Cloudflare account-level logging and retention settings have not been verified.

First observed runs are not DMG download or installation counts. Existing installations are first observed when they run a version with statistics enabled. Offline use, short sessions, opt-outs and retries can produce missing or duplicate counts. No persistent user identifier is sent, and the analytics dashboard's unique-user counts must not be treated as reliable user totals. Disabling sharing does not delete statistics already received by the server.

The default build is ad-hoc signed, without Developer ID signing or Apple notarization. Physical Intel hardware, macOS 13, server reboot/backup restoration and the full test suite have not been exercised for this release.

## Validation

The final focused checks pass 11 statistics and UI tests plus 30 existing settings compatibility tests, along with the Apple Silicon Release build. Earlier feature-hook validation passed 91 focused tests covering settings, plugins, formatting and editor operations. All eight localization catalogs pass key and format checks; privacy settings and the narrow first-run notice were checked in light/dark layouts and inspected in captured windows for every supported language.

Independent code review and re-review resolved lifecycle-delivery and login-email rate-limit findings. Isolated proxy tests cover registration blocking, per-IP and global sign-in limits, ingestion header stripping and login continuation. The deployed server passed public health, blocked-registration and Debug-event ingestion checks.
