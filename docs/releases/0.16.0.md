# Duckpad 0.16.0

Markdown documents gain a bundled CodeMirror 6 editor with Source and Live editing in the same document. Other file types continue to use Scintilla.

## Changes

- Render headings, emphasis, inline code, tasks, lists, local images, editable tables, KaTeX math and Mermaid diagrams while editing Markdown. Preserve native Undo/Redo, UTF-8 bytes, mixed line endings and pending composition across Save and recovery boundaries.
- Edit table cells with a plain caret and stable column widths. Navigate cells with arrow keys, Tab and Shift-Tab; use the contextual menu for clipboard, rows and columns.
- Use Command-click to follow web links in the default browser and file links in Duckpad. Match Markdown surfaces, syntax and diagrams to the workspace palette.
- Replace the separate Markdown preview window and tab preview actions with Source/Live editing. Use Shift-Command-V to switch modes. Click math to edit its source; display math keeps a live result beneath its source. Formatted copy and shared table rendering remain available. Raw HTML remains editable source.
- Keep presentation fixed while dragging a selection; reveal selected Markdown after release. Update changed Markdown blocks and indexed byte coordinates instead of scanning the whole document on each keystroke.
- Drag files directly from Workspace Explorer into editor splits. Split a newly opened or sole tab without having to create another split first.
- Reconnect failed remote Tail at the latest file end, retaining the last readable snapshot until a bounded reload succeeds.
- Keep two Tail panes following after split/resize and asynchronous line wrapping. Pausing one pane preserves its selection and viewport while other panes keep following.

App and all three helpers: **0.16.0 (68)**, upgrading **0.15.1 (67)**. Requires **macOS 13 or later**. Universal binaries include Apple Silicon and Intel. Existing documents, settings, recovery data and the native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.16.0-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.16.0-universal.zip`. Verify downloads against `SHA256SUMS.txt`.

## Validation and limitations

**64 distinct focused Release test functions completed**, covering Source/Live, math and offline fonts, table arrows and composition, native byte mirrors, Save/Undo/recovery, language transitions, split teardown, image grant lifetime and Tail reconnect/following. Twenty-seven JavaScript tests and independent randomized byte/decoration checks also pass. Localization keys and format arguments are verified across all eight languages; all locales were not manually inspected.

The final universal app and three helpers must pass bundle/signature checks, isolated application/Markdown/localization smoke and archive verification before publication. Native Save-panel automation is excluded. Two broader tests remain failing outside the focused pass claim: the folder-search routing fixture and a legacy Replace shortcut expectation (Cmd-H versus the unchanged Cmd-R menu). Full-suite completion is not claimed. A transient combined-run drop-proposal failure passed on isolated rerun.

Synthetic transaction/bridge timings are not physical keyboard-to-paint latency or a runtime comparison with Obsidian. Installed Obsidian 1.8.9 was statically inspected for architecture; no proprietary source is incorporated. Large Markdown blocks and diagrams still require work proportional to their contents.

Physical Korean keyboard input, Intel hardware execution and macOS 13 runtime require separate verification. The distribution is ad-hoc signed, without Developer ID signing or Apple notarization.
