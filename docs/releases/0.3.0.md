# Duckpad 0.3.0

Duckpad now speaks eight languages, with a refreshed app icon and larger file icons.

## What's new

- Bundled interface translations for English, Korean, Japanese, Simplified Chinese, Brazilian Portuguese, Italian, French, and German. No language plugins or downloads are needed.
- Choose **Preferences → General → App Language**, then restart Duckpad. The default follows macOS, with English as the fallback.
- Translated menus, preferences, search, document comparison, About and update checks, alerts, and accessibility descriptions.
- Search the command palette using either English or translated command names.
- Refreshed the app icon with the new Duckpad artwork and less horizontal padding.
- Enlarged file icons in tabs, the workspace tree, and the open-document list by approximately 30%, preserving surrounding padding.
- Updated the README with the Duckpad artwork and supported-language checklist.

Long search controls remain reachable by horizontal scrolling in narrow windows. Keyboard shortcuts, document contents, file names, and encodings are unchanged by the interface language.

Includes the About Duckpad window, update checks, and Help links introduced in 0.2.1.

App and plugin runtime version: **0.3.0 (7)**.

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.3.0-universal.dmg` and drag Duckpad to Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also available.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

Translations have automated resource and behavior checks; fluent-speaker review is still welcome.
