# Duckpad 0.16.1

This patch fixes Explorer-to-editor splits, closing shared tabs, and the integrated terminal's login security session and locale.

## Fixes

- Split a file immediately after opening it from Workspace Explorer. The drag destination now receives updated tab membership alongside incremental tab-strip updates.
- Drop an unopened Explorer file onto a split edge without leaving an unnecessary copy in the original pane. Already open files can still gain another view.
- Close only the invoking pane's shared tab with its close button, current-tab context action or Command-W. Keep the remaining document's dirty content and native Undo/Redo until its last view closes. Drain pending editor input before disposal and abort stale closes if another persisted removal starts while input is being synchronized. Close-all actions retain document-wide behavior.
- Run the integrated terminal's XPC helper in the caller's login security session. This addresses the missing session connection associated with Git credential-helper errors `failed to get: -25308` and `failed to store: -25308`. Keychain item permissions and locked-keychain authorization still apply.
- Preserve explicit `LANG`, `LANGUAGE` and standard `LC_*` settings. Finder launches without `LANG` use an available system UTF-8 locale, falling back to `en_US.UTF-8`, rather than forcing English for every shell. Application display-language settings remain independent of shell locale.

App and all three helpers: **0.16.1 (69)**, upgrading **0.16.0 (68)**. Requires **macOS 13 or later**. Universal binaries include Apple Silicon and Intel. Existing documents, recovery data, settings and plugin ABI remain compatible. No new dependencies are added.

## Installation

Download `Duckpad-0.16.1-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.16.1-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Existing installations can use Check for Updates after the signed feed is published.

## Validation and limitations

Focused checks cover immediate first splits, the Explorer open callback followed by a drag, shared-tab close routes, overlapping input synchronization and persisted removal, dirty Korean text, native Undo/Redo, group routing and locale precedence. Before/after regressions reproduce the reported split failures and the overlapping-close failure. **115 distinct focused Release test functions completed**, recorded in `0.16.1-validation.json`.

Before publication, the final merged-source universal app and all three helpers must pass version/architecture/signature checks, isolated application and Markdown smoke, all eight packaged localization smokes, archive integrity and uploaded asset hash verification. The packaged terminal helper's login audit session is checked against its owning app. Native Save-panel automation is skipped.

Actual account `git pull` authentication, physical pointer dragging and Korean keyboard interaction, Intel hardware, macOS 13 runtime, and full repository suite completion are not claimed. Caret, scroll and Markdown mode inheritance during secondary-to-primary pane promotion have not been specifically verified. Broader search-test limitations documented in 0.16.0 remain outside this patch's focused validation. The distribution is ad-hoc signed, without Developer ID signing or Apple notarization.
