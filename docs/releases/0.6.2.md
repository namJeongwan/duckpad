# Duckpad 0.6.2

- Add **Uninstall** for user-installed plugins. Uninstall stops their commands and panels while retaining history and settings for reinstallation. Bundled plugins remain disable-only.
- Fix **Command-W** while keyboard focus is inside a plugin panel: close that panel instead of the document or main window. With focus in the editor, normal document-close behavior is retained.
- Refresh native resize cursors at the window's borders and corners on macOS 15 or later, and restore the content cursor when returning to the editor. Drag feedback and native resizing remain unchanged.

App and helpers: **0.6.2 (40)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel Macs.

## Install

Download `Duckpad-0.6.2-universal.dmg`, open it, and drag Duckpad into Applications. A ZIP archive and SHA-256 checksums are also provided.

This build is ad-hoc signed and **not notarized by Apple**. Physical Intel hardware and macOS 13 hardware have not been tested.

Clipboard History is downloaded separately from **Plugins → Manage Extensions**. Version **0.3.2** adds copied bitmap images and Finder image files, thumbnails, bounded previews, and Copy Image. Updating an already loaded native plugin takes effect after restarting Duckpad. Its release notes describe image-format support and history compatibility.

## Validation and limits

The changes passed focused uninstall, panel-close, and cursor regression tests and independent review. The cursor smoke checks cover eight edges/corners, editor cursor restoration, drag feedback, and non-resizable windows. The original intermittent cursor trigger remains unreproduced; the change provides defensive recovery, while macOS 13–14 retain native cursor behavior.

Native libraries remain mapped until process exit. Uninstalling a plugin stops its behavior but cannot unload its code from the current process. A previously accepted installer request can leave an inactive execution cache, without reactivating the removed plugin.
