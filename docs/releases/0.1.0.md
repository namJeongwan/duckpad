# Duckpad 0.1.0

Notepad++의 익숙한 편집 경험을 Mac에서도 이어가기 위한 첫 번째 릴리스입니다.

## 주요 기능

- 여러 줄 탭, 탭 고정과 드래그 이동, 최대 4개 편집 패널
- 구문 강조, 찾기·바꾸기, 인코딩·줄바꿈 형식 선택
- 저장하지 않은 문서를 포함한 세션 복원
- macOS 네이티브 메뉴와 시스템·Light·Dark 테마

## 설치

macOS 13 이상에서 실행할 수 있습니다. `Duckpad-0.1.0-universal.dmg` 하나에
Apple Silicon(arm64)과 Intel(x86_64) 실행 파일이 모두 들어 있습니다.
DMG를 열고 Duckpad를 Applications로 옮겨 주세요.

이번 배포본은 ad-hoc 서명을 사용하며 Developer ID 서명과 Apple 공증을 받지
않았습니다. 인터넷에서 내려받은 앱을 처음 실행할 때 macOS가 실행을 차단할
수 있습니다. 출처를 확인한 뒤 실행하려면 [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를
참고해 주세요. 정식 서명·공증은 아직 제공하지 않습니다.

ZIP 파일도 같은 앱을 담고 있습니다. `SHA256SUMS.txt`로 다운로드 파일의
체크섬을 확인할 수 있습니다.

## 참고

- 0.1.0은 초기 릴리스이며 사용성과 세부 동작을 계속 다듬고 있습니다.
- 앱 종료·로그아웃·재시작 때 작업 상태를 보관하며, 원본 파일에 변경 내용을
  기록하려면 Save를 사용합니다. 탭을 직접 닫을 때는 저장 여부를 확인합니다.
- Intel 실행 파일은 Universal 빌드와 Apple Silicon Mac의 Rosetta 실행으로
  검증했습니다. 실제 Intel Mac 하드웨어 검증은 포함하지 않습니다.

문제나 개선 제안은 [Issues](https://github.com/namJeongwan/duckpad/issues)에 남겨 주세요.
