# Duckpad 0.1.0

The first release of Duckpad, a macOS text and code editor inspired by Notepad++.

## Features

- Multi-row tabs, pinned tabs, and drag-to-split editing in up to four panels
- Syntax highlighting, find and replace, and encoding and line-ending controls
- Session restoration, including unsaved documents
- Native macOS menus and System, Light, and Dark themes

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.1.0-universal.dmg` and drag Duckpad to Applications. The ZIP contains the same app; use `SHA256SUMS.txt` to verify either download.

This early release is ad-hoc signed, without Developer ID signing or Apple notarization. macOS may block the first launch. See [Apple's instructions for opening an app](https://support.apple.com/en-us/102445) after verifying its source.

## Notes

- Quitting, logging out, or restarting preserves your session. Use Save to write changes to the original file; closing an unsaved tab prompts for confirmation.
- Intel execution was tested through Rosetta on an Apple Silicon Mac, not on physical Intel hardware.
