# Duckpad 0.2.0

More control over your editor, with smoother tabs and live file updates.

## New

- **Editor fonts:** Search installed fonts and preview each typeface. Font sizes update as you type, with decimal values and up/down controls.
- **Live file updates:** Automatically reload files changed by other apps. Unsaved edits are preserved, with a choice to keep editing or reload from disk.
- **Preferences:** More controls for tabs, indentation, guides, recent files, file-dialog locations, and Find/Replace behavior.
- **File comparison:** View differences in a separate window.

## Improvements and fixes

- Refined tab icons, modified indicators, and navigation controls. Closing many tabs is faster.
- Improved tab dragging between editor panels, split creation, and drop feedback.
- Reopen an already-open file using a different encoding, while protecting unsaved edits. Encoding menus distinguish reopening from converting and saving.
- Fixed redundant Undo entries and made typing/deletion start a new Undo group after a pause.
- Fixed font-search typing, unreadable symbol-font names, and clipped font previews.

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.2.0-universal.dmg` and drag Duckpad to Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also available.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

Intel execution is tested through Rosetta on an Apple Silicon Mac; physical Intel hardware testing is not included.
