# Duckpad 0.6.3

- Keep the original tab visible while dragging, with a compact preview at the pointer and primary-color drop feedback. Fix the preview animating in from the window edge.
- Show search matches across the scrollbar width with translucent markers. Click a marker to reveal the exact match; the scrollbar thumb remains draggable.
- Align search markers with wrapped text, folded lines, resized windows, and each split pane. Separate matches inside one long JSON line retain their own positions.
- Mark changed lines in the gutter: orange for unsaved changes, green after saving, and blue for changes reverted to the original state. Undo and Redo update these markers.
- Keep ordinary paced typing in one Undo group by increasing the idle boundary from 300 ms to 1 second. Explicit edit groups and active IME composition remain intact.

App and helpers: **0.6.3 (41)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel Macs.

## Install

Download `Duckpad-0.6.3-universal.dmg`, open it, and drag Duckpad into Applications. A ZIP archive and SHA-256 checksums are also provided.

This build is ad-hoc signed and **not notarized by Apple**. Physical Intel hardware and macOS 13 hardware have not been tested.

## Validation

Focused native editor, search overview, save-point, and tab-drag regression tests passed, including Korean composition, Undo/Redo, dense translucent markers, and 2,000 matches in a single wrapped line in a cloned pane. Native UI checks covered drag previews, retained source tabs, scrollbar visibility, and wrapped-document search rendering. Independent reviews covered the final implementation.
