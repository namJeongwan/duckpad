# Duckpad 0.12.2

Changing a document's encoding or LF/CRLF/CR line endings now marks it unsaved instead of immediately overwriting the file. Format changes share the normal Undo/Redo history with typing; Save or Save As writes the selected format to disk.

- Undo and redo format changes with Command-Z and Shift-Command-Z. Undo after saving changes the document and marks it unsaved; disk bytes change only on the next save.
- Pending encoding and line-ending choices survive session recovery, including unnamed documents. Reload groups text and format changes into one undoable action. Undo history itself remains limited to the current session.
- Add explicit open/reopen and conversion for CP949, EUC-KR, Shift-JIS (CP932), Windows-1252, Windows-1251, ISO-8859-1, GB18030, and Big5. Invalid input or characters that cannot be represented are rejected without silently replacing characters.
- Keep dirty state and pending format consistent when Undo overlaps a save, recovery metadata persistence fails, or a file write has an uncertain durability outcome.
- Include the editor control alignment, hover spacing, and close-flow refinements merged after 0.12.1.

App and all helpers: **0.12.2 (60)**. Requires **macOS 13 or later**. Universal distribution binaries support Apple Silicon and Intel. Existing UTF/BOM files, session recovery, settings, and the native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.12.2-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.12.2-universal.zip`. Verify downloads against `SHA256SUMS.txt`.

## Validation and limitations

The related Swift suites pass **256 test functions**, including native editor Undo/Redo, reload, named/unnamed recovery, IME rejection, selection preservation, strict encoding fixtures, save failures, and concurrent editing. All eight localization catalogs pass validation (796 strings and four plural entries). Independent implementation review resolved the identified save-state and transaction-handoff issues.

Automatic opening and unopened-file folder search remain UTF/BOM based; ambiguous legacy files require explicit encoding selection. Full manual inspection in all eight languages, the entire test suite, physical Intel hardware, and macOS 13 were not exercised. Packaged artifact verification and isolated launch smoke results are recorded with the published release.

The default distribution is ad-hoc signed, without Developer ID signing or Apple notarization.
