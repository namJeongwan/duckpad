# Duckpad 0.10.0

Duckpad now supports the separately installed PlantUML plugin, plus native
PlantUML syntax colors and clickable hexadecimal color previews in the editor.

- Highlight `.puml`, `.plantuml`, `.pu` and `.wsd` files, with structural detection
  for unrecognized files beginning with a supported PlantUML directive.
- Show hexadecimal color chips in the gutter of supported styled documents.
  Click a chip and apply a color as one undo operation. Chips follow scrolling;
  read-only files retain the preview and IME composition disables color edits.
- Provide bounded current-document reads through native host API 1.4.0.
- Render PlantUML locally using a sandboxed JVM, reused until ten idle minutes.
  Runtime setup and offline paths are exposed by the separately installed plugin.
- Correct current-line background painting so the configured theme color fills
  both text and line remainder without a black translucent overlay.

App and helpers: **0.10.0 (52)**. Requires **macOS 13 or later**. The release build
contains Apple Silicon and Intel binaries. Existing documents, sessions and
workspace preferences remain compatible. Existing native ABI 1 plugins retain
compatibility; PlantUML 0.1.0 needs host API 1.4.0 and cannot load on older hosts.

## Installation

Download `Duckpad-0.10.0-universal.dmg` and drag Duckpad into Applications, or
extract `Duckpad-0.10.0-universal.zip`. Verify against `SHA256SUMS.txt`.
PlantUML is distributed separately from
[duckpad-plugin-plantuml](https://github.com/namJeongwan/duckpad-plugin-plantuml)
and listed in the [plugin catalog](https://github.com/namJeongwan/duckpad-plugins).
No Java or PlantUML JAR is embedded in Duckpad or the plugin archive.

The default build is ad-hoc signed, without Developer ID signing or Apple
notarization. In-app update availability requires publication of the signed
Sparkle feed after the release archive is uploaded.

## Validation and limitations

Regression coverage checks syntax roles, color-chip scrolling and bounded color
edits, undo/recovery, shared-pane IME guards, native ABI authorization, and current
line background pixels. Runtime smoke tests check warm rendering, idle shutdown,
cancellation, path changes, invalid inputs and process-group cleanup. Plugin
localization catalogs contain matching keys in all eight translations.

Highlighting is structural rather than complete PlantUML grammar validation.
Preview rendering supports one complete diagram up to 512 KiB, a 90-second limit,
a 512 MiB Java heap and 32 MiB output. Diagram types needing external Graphviz
remain outside the first plugin release. Physical Intel hardware and macOS 13
have not been tested. Physical-platform coverage remains limited to the available Apple Silicon machine.

## Validation

- 29 focused editor, bounded document-read, language and native-plugin activation tests passed.
- Host localization validated 733 strings and four plural entries in all eight languages; the plugin has 39 matching keys per locale.
- Native plugin ABI, compact UI at 300/560-point widths in all eight languages, Control-W with English/Korean input and teardown checks passed.
- The supplied large Korean sequence rendered to PNG and SVG. Warm PNG rendering reused the JVM (about 0.26 seconds versus 0.88 seconds cold on the test machine). Idle reset/expiry, restart, path changes, invalid inputs, cancellation, entropy/private-file isolation and process-group cleanup checks passed.
- Universal host/plugin builds, app/helper versions, resources, entitlements, Mach-O signatures, Ed25519 plugin inventory and archive checks passed during release preparation.
- Host smoke checks passed Finder/Open With, security-scoped recovery/save, window layout and sandboxed XPC isolation. Optional automated native save-panel interaction was skipped.

Physical Intel hardware and macOS 13 execution were not tested. Default binaries are ad-hoc signed and not Apple notarized. PNG/SVG export and local rendering require the separately installed compatible plugin and verified Java/JAR runtime.
