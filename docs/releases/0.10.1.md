# Duckpad 0.10.1

This patch fixes plugin panel controls and session-save failures when another
Duckpad instance has advanced the recovery store.

- Press a plugin's opening shortcut again to close its panel. Repeating the
  command while a native panel is still opening cancels that presentation.
- Restore each plugin command's last dock width, including when opened in
  another editor window. Native panels finish layout before restoring the divider.
- Control-W cancels the active modal or sheet, then closes an active auxiliary
  window or the editor's plugin/preview panel. It does not close the document
  underneath. Command-W also dismisses an attached modal before a document.
- Retry valid recovery-generation collisions and verify the current session's
  durable archive before quitting. Persistent storage errors remain visible
  after Retry and continue to prevent an unsafe exit.

App and helpers: **0.10.1 (53)**. Requires **macOS 13 or later**. Universal binaries
support Apple Silicon and Intel. Existing documents, sessions, native plugin ABI
and settings remain compatible. Plugins remain separate downloads; this release
does not install or enable them.

## Installation

Download `Duckpad-0.10.1-universal.dmg` and drag Duckpad into Applications, or
extract `Duckpad-0.10.1-universal.zip`. Verify the files against `SHA256SUMS.txt`.
The signed Sparkle feed is published after the release archive is uploaded.

## Validation and limitations

Focused regression checks cover plugin command toggles, panel width restoration,
pending presentation cancellation, multiple editor windows, modal-first closing,
recovery collisions, termination durability and persistent retry failures.

Recovery commits remain last-writer-wins: separate running instances are not a
collaborative editing session and their independent edits are not merged. Genuine
corruption and storage failures still require recovery or a successful retry.
Dock height follows the editor window; plugin width is remembered per command.

The default build is ad-hoc signed, without Developer ID signing or Apple
notarization. Physical Intel hardware, macOS 13, live Korean IME and interactive
system picker behavior were not tested for this patch.
