# Duckpad 0.3.2

Search now opens in a compact, separate window and highlights every matching part of the document.

## Changes

- Organize search into Find, Replace, Find in Files, and Bookmarks tabs, with inputs on the left and relevant actions on the right.
- Highlight all matches in green in both light and dark appearances. Keep the highlights visible while moving between matches, and refresh them after edits and Undo.
- Preserve the original editor selection when enabling **In selection**, and keep subsequent searches within that range.
- Give the transparency slider a solid track and thumb. Keep the window fully opaque while dragging, with a minimum opacity of 50% afterward.
- Keep incremental searches and match counts compact; expand the result list only for explicit Find All or folder searches.
- Bookmark matching lines while preserving text, selections, and Undo history.
- Add the new search interface strings to all eight bundled languages.

App and plugin runtime version: **0.3.2 (9)**.

## Installation

Requires **macOS 13 or later**. The Universal app supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.3.2-universal.dmg` and drag Duckpad into Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also provided.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

## Verification and scope

37 focused regression tests passed, covering search, selected ranges, replacement, bookmarks, Undo, and search preferences. Light/dark search screenshots and the new translation keys in all eight languages were checked.

Find in Files uses recursive read-only folder search; file filters, folder replacement, and project search are not included. Four existing binary-file interface strings remain untranslated in six languages other than English and Korean. Physical Intel hardware and a separate manual IME/slider-drag session were not tested for this release.
