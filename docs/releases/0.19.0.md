# Duckpad 0.19.0

Find/Replace in Files now highlights the syntax in its read-only code preview.
Keywords, strings, comments, numbers and operators use the editor's existing
Lexilla language definitions and light/dark colors. The yellow search match
remains visible above syntax colors. Open buffers respect manual language
selection; closed files use filename and document-start detection, including
extensionless Python and Ruby scripts with shebangs.

The preview uses a separate lexer without sharing the source document or its
Undo history. Theme updates preserve selection and scrolling. Switching between
canonically equivalent Unicode text with different underlying bytes replaces
the exact source before applying attributes, avoiding a range exception.

## Compatibility and installation

The app and all three helpers are **0.19.0 (75)**, upgrading **0.18.3 (74)**.
Requires macOS 13 or later; the universal app includes Apple Silicon and Intel.
Host API **1.6.0**, native ABI v1 and independently released plugins are unchanged.
No dependencies were added or upgraded.

Download `Duckpad-0.19.0-universal.dmg` or `Duckpad-0.19.0-universal.zip` and verify
against `SHA256SUMS.txt`. After the tap update, Homebrew installations can run:

```sh
brew update
brew upgrade --cask --greedy namjeongwan/duckpad/duckpad
```

Existing installations can use **Check for Updates** after the signed feed is
published. Distribution is ad-hoc signed, without Developer ID signing or Apple
notarization.

## Validation and limits

The Release arm64 build and **20 focused test functions** passed: native syntax
colors for Rust, Python, Ruby, JSON and YAML; multiline comments; distant shebang
detection; malformed UTF-8 ranges; NFC/NFD preview transitions; light/dark search
overlays; actual closed-file and unsaved manual-language search paths; and
existing preview, query-stability and streamed-result regressions. Light/dark
preview snapshots were inspected. Source bytes, language and Undo history were
preserved. Independent adversarial review reproduced the Unicode crash before
the fix and successful transitions after it, with no unresolved findings.

Visible text is capped at 32 KiB, preceding lexer context at 64 KiB, and the
separate document-start language probe at 64 KiB. Multiline constructs beginning
before the preceding-context window may have approximate colors. Plain text
and unsupported lexers keep the normal preview foreground.

The universal release app was built from clean merged main commit
`d1be412342da56c32f8f4003411385fc5aedaa9b`. Bundle/resources/signatures,
app and all three helper versions/architectures, default app smokes, all eight
packaged locales and DMG/ZIP integrity passed. Packaged Markdown resources retain
the earlier caret fix.

Intel hardware, macOS 13 runtime, physical Korean IME and a full repository suite
are not claimed as tested. Optional native Save-panel automation was skipped.
