# Duckpad 0.1.3

Restore file access directly from the save flow.

## Fixes

- If saving fails because access expired or a file is missing, Duckpad opens a native save dialog. Select the same file to restore access, or choose a new destination; saving then resumes without reloading your edits.
- Fix saving new files in the sandbox: keep the selected-file grant while writing, then create the persistent bookmark after the file exists.
- Keep renewed access across relaunches and external-change reloads. Cancellation preserves edits, and external-change checks still apply.
- Support access recovery for Save, Save As, Save All, Save a Copy As, and saving when closing a tab.

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.1.3-universal.dmg` and drag Duckpad to Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also available.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

Intel execution is tested through Rosetta on an Apple Silicon Mac; physical Intel hardware testing is not included.
