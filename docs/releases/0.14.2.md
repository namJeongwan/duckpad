# Duckpad 0.14.2

See filename-search results as they are discovered, without waiting for a large workspace to finish scanning.

- Double-Shift filename search now streams validated results immediately and refreshes them approximately every 50 ms as discovery continues. All, Workspace and Folder scopes use the same progressive path. Bundled `rg --files` discovers names; Duckpad performs literal case/diacritic-insensitive matching and ranking without reading file contents.
- Reduce the filename-input debounce from 120 ms to 20 ms. Keep usable rows visible while the complete result set is ranked in the background. Rows outside a newly selected scope or query disappear immediately.
- Preserve keyboard and mouse selection across progress updates, including selections changed while asynchronous ranking is running. New queries, scope changes, dismissal and changed workspace roots reject stale results.
- Avoid repeated URL construction while mapping names. Cache directory package classification only within each search and within bounded memory; path-component open/no-follow/fstat checks, root identity checks, hidden-file preferences and ignore rules remain in force. File opening revalidates access.

App and helpers: **0.14.2 (64)**, upgrading **0.14.1 (63)**. Requires **macOS 13 or later**. The universal distribution supports Apple Silicon and Intel. Existing settings, recovery data, encodings, Undo history and the native plugin ABI remain compatible. No new dependencies or user-facing strings are added.

## Installation

Download `Duckpad-0.14.2-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.14.2-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Existing installations can use Check for Updates after the signed update feed is published.

## Validation and limitations

Focused validation passed **66 related Swift test functions** across presentation, infrastructure and application. Coverage includes progress before a held search completion, continuously updated rows, selection changes during asynchronous ranking, large scope transitions, stale queries, Korean composition notifications, filename ranking/design, workspace access, ignore/hidden-file behavior and symlink rejection. Independent review found no remaining Blocker, Major or Minor issues. The final universal app is verified and exercised with isolated packaged smoke checks before publication.

One local debug-backend measurement on a workspace containing approximately 379,000 discovered names delivered the first `util` result in **14.13 ms**, followed by 120 progress snapshots and all 4,383 matches in 6.25 seconds without truncation. Previously, no results were returned until completion at 7.34 seconds. These are individual warm-filesystem backend observations, not guaranteed end-to-end UI or cold-filesystem latency. Large directory traversal can still take seconds while results remain usable.

Filename search retains at most 20,000 matching names and displays up to 100 ranked results. Discovery retains existing time and stream limits; progress delivery keeps only the latest pending snapshot. Workspace roots are visited in their existing order. Incomplete results retain the existing truncation indication.

The full repository test suite, physical Korean keyboard interaction, full manual inspection in all eight languages, Intel hardware and macOS 13 runtime were not exercised. Native Save-panel automation is explicitly skipped by the isolated smoke script.

The distribution is ad-hoc signed, without Developer ID signing or Apple notarization. No separately installed ripgrep, Node or Ghostty application is required.
