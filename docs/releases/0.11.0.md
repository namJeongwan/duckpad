# Duckpad 0.11.0

Navigate code without installing a language server.

- Hold Command over an identifier to underline an available declaration candidate and show a link cursor. Command-click or F12 opens the declaration; ambiguous matches show a searchable list with file, line and code context.
- Shift-F12 finds reference candidates in the current document, compatible open buffers and registered workspace roots. Unsaved buffers take precedence over disk contents. Comments, string literals and recognized declarations are excluded.
- Control-minus and Control-Shift-minus navigate backward and forward. Jumps expand folded targets and place the destination near the top fifth of the active pane, including wrapped lines.
- Common declarations are supported in Swift, JavaScript/TypeScript, Python, Rust, Go, C/C++, Java, C# and Protocol Buffers. Protobuf RPC request/response types navigate to their message declarations.
- Hover and click share completed lookup results. Editing another tab, reloading the source or changing its language invalidates stale results.
- Localization now resolves both flat SwiftPM resource bundles and macOS bundles containing `Contents/Resources`.

App and helpers: **0.11.0 (57)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel. Document formats, sessions, settings, Undo/Redo and the native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.11.0-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.11.0-universal.zip`. Verify the downloads against `SHA256SUMS.txt`. The signed Sparkle update feed is published after the release archive is uploaded.

## Scope and limits

Built-in navigation is syntax/name based. Reference candidates can include unrelated symbols with the same name; receiver types, imports, overloads and semantic bindings require a future language-server provider. Project lookup uses registered workspace roots and UTF-8 files. Other encodings can participate through an already-open buffer.

Analysis is bounded to 4 MiB and 200,000 tokens per source. Open-buffer lookup is limited to 16 MiB; project lookup stops at 256 directories, 512 files, 10,000 entries, 32 MiB, 200 results or a cooperative three-second deadline. Partial results are labelled. A filesystem read already in progress may exceed the deadline. Larger documents remain editable; built-in navigation is unavailable for them.

## Validation

All 1,193 Swift tests passed: 461 presentation, 346 editor adapter, 208 application, 161 infrastructure, 14 domain and 3 app tests. Presentation tests ran in isolated serial helper processes with completion counts verified because Xcode’s SwiftPM helper can exit its main event loop before finishing a combined AppKit run. The previous test-helper concurrency compilation error is fixed.

All eight candidate-panel localizations were rendered and inspected; catalog, layout, accessibility and fallback checks passed. Navigation tests cover unsaved buffers, Protobuf RPC types, hover/click reuse, stale content and language rejection, partial results, folding, wrapping and history.

A full Release input matrix covered 14 approximately 9.18 MB fixtures (JSON, JavaScript, CSS, XML, plain/Unicode/tab-heavy text, logs and multiline sources). The final accepted fixture runs passed all 10,752 editing events with a 43.19 ms maximum; first-input cycles (input handling plus native queries, status, drawing and layer flush) reached at most 27.06 ms. Loading precedes these measurements. Initial emoji, combining-character and original-JSON stress runs exceeded 50 ms (147.11, 63.85 and 67.15 ms); clean 0.10.4 comparison runs and unchanged 0.11.0 rechecks passed. The spikes did not reproduce, and their cause is not established. All measurements, including failures, are retained in the validation evidence; these fixture-specific results are not a hard real-time guarantee for arbitrary workloads or system load.

[Validation evidence](https://github.com/namJeongwan/duckpad/blob/v0.11.0/docs/features/declaration-navigation-validation.json).

The default build is ad-hoc signed, without Developer ID signing or Apple notarization. Physical Intel hardware, macOS 13 and live Korean IME are not exercised on the development Apple Silicon machine. Automated native tests cover IME cancellation, Unicode input, selection and Undo/Redo.
