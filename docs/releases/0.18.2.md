# Duckpad 0.18.2

The workspace explorer can refresh files added, deleted or renamed outside Duckpad.
Use the Refresh arrow in the sidebar header or Refresh in its context menu.
Previously, an expanded directory kept its cached listing until it was rebuilt.

Refresh revalidates registered folders and reloads cached directories. Retained
folders keep their expansion, selection and scroll position; an active filename
filter reruns without clearing its query. Pending older directory successes and
failures cannot overwrite refreshed results. Refresh during initial navigation
restore restarts that restore. Open documents and unsaved buffers remain intact.
This patch provides manual refresh; it does not add automatic filesystem watching.

## Compatibility and installation

The app and all three helpers are **0.18.2 (73)**, upgrading **0.18.1 (72)**.
Requires macOS 13 or later; the universal app includes Apple Silicon and Intel.
Host API **1.6.0**, native ABI v1 and independent plugin releases are unchanged.
No runtime dependencies were added or upgraded.

Download `Duckpad-0.18.2-universal.dmg` or `Duckpad-0.18.2-universal.zip` and verify
against `SHA256SUMS.txt`. Homebrew installations can run after the tap update:

```sh
brew update
brew upgrade --cask --greedy namjeongwan/duckpad/duckpad
```

Existing installations can use **Check for Updates** after the signed feed is
published. Distribution is ad-hoc signed, without Developer ID signing or Apple
notarization.

## Validation and limits

Regression tests use temporary filesystem projects and an isolated native editor
session. Coverage includes external create/delete/rename, dirty-buffer and tree
navigation preservation, active filters, no-root controls and all eight locales,
late cancellation-ignoring directory success/failure, and refresh during the first
saved-navigation read. The missing-control and interrupted-startup cases were
reproduced before their fixes. Related workspace, hidden-file and filesystem
store tests accompany these regressions.

The final Release selection passed **34 Presentation**, **7 Infrastructure** and
**9 Application** tests, including both single and overlapping initial refresh.
The universal app was rebuilt from clean merged main commit
`a57ff0d3effe598cabc80d22c2021a07b53266b0`. Bundle/resources/signatures,
app and all three helper versions/architectures, default app smokes, all eight
packaged locales and DMG/ZIP integrity passed. Packaged Markdown resources still
match the 0.18.1 caret fix. User documents and recovery sessions were not modified.

Intel hardware, macOS 13 runtime, physical Korean IME and a full repository
test-suite run are not claimed. Optional native Save-panel automation was skipped.
