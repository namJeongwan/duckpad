# Duckpad 0.9.1

This patch improves workspace navigation and makes the sidebar, menus, tabs, status bar, and editor surfaces more consistent.

- Resize the workspace sidebar by dragging its boundary. Its width is preserved when hidden and shown again.
- Show or hide the workspace with **Command-B**, the sidebar button, or the View menu. Workspace open/close commands and accessibility descriptions are localized in all eight supported languages.
- Long file names retain their full text and can be read with horizontal scrolling. Hovering over a clipped name immediately reveals its full name on the same row, extending beside the sidebar. The expansion does not take keyboard focus or intercept file clicks, and closes when the pointer leaves, the workspace scrolls, or the window changes.
- File icons match editor tabs. Sidebar rows, controls, hover states, and light/dark colors use consistent spacing and surfaces. Editor indentation guides and fold markers are quieter.

App and helpers: **0.9.1 (50)**. Requires **macOS 13 or later**. Includes Apple Silicon and Intel binaries. Existing documents, session formats, and the `duckpad` terminal command remain compatible.

## Installation

Download `Duckpad-0.9.1-universal.dmg`, open it, and drag Duckpad into Applications. Alternatively, extract `Duckpad-0.9.1-universal.zip`. Verify downloads against `SHA256SUMS.txt`. In-app updates become available after publication of the signed Sparkle feed.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. The Sparkle archive uses a separate Ed25519 signature.

## Validation and limitations

Regression checks cover sidebar sizing, width restoration, scrolling, immediate filename expansion, focus preservation, expansion dismissal, workspace commands, localized menus, icon reuse, and native editor guides/folding. A separate preview session was used to check sidebar dragging, mouse/Command-B toggling, and horizontal scrolling without editing user documents.

The physical pointer's filename hover expansion could not be visually confirmed through the UI automation tool; synchronous hover-event tests verify its native panel, full text, alignment, and cleanup. Physical Intel hardware and macOS 13 execution were not checked. Only Korean preview UI was manually inspected; all eight localization resources are checked for matching keys. Final package, archive, smoke, and update-feed results are recorded in the published release.
