# Duckpad 0.8.0

Duckpad adds file-based EditorConfig rules, indentation detection, optional save cleanup, and reusable snippets. These features are built into the app and do not require plugins.

- Read `.editorconfig` from a saved file's folder and accessible ancestors. Supported rules cover indentation, tab width, line endings, UTF-8/UTF-16 encoding, trailing whitespace, and final newlines. Explicit rules take precedence over detected indentation and app defaults.
- Detect existing tab/space indentation from a bounded sample without rewriting the document. EditorConfig and detection are enabled by default and can be disabled in Preferences.
- Optionally remove trailing spaces or add a final newline on save. Both app-wide cleanup options default to off; file rules can override them. Changes participate in Undo and recovery, with existing external-file conflict checks preserved.
- Use **Edit → Snippets…** to save and insert reusable text. Templates support numbered placeholders, linked occurrences, Tab/Shift+Tab navigation, a final cursor position, and optional language scope.
- Localize the new controls in all eight supported languages.

This release also includes the rich clipboard copying previously merged after 0.7.2: Markdown can be copied as rendered content, and code can retain editor formatting for compatible rich-text destinations.

App and helpers: **0.8.0 (47)**. Requires **macOS 13 or later**. Distribution includes Apple Silicon and Intel binaries.

## Installation

Download `Duckpad-0.8.0-universal.dmg`, open it, and drag Duckpad into Applications. The ZIP alternative is `Duckpad-0.8.0-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Users on 0.7.0 or later can update in the app once the signed Sparkle feed is published.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. Sparkle archives use a separate Ed25519 signature.

## Compatibility and limitations

Unsaved documents have no folder-based EditorConfig rules until saved. macOS sandbox permissions can prevent access to a sibling configuration file; grant access to the folder or open `.editorconfig` once in that case. Existing text is not automatically reformatted on open. Enabling trailing-space cleanup also removes Markdown's two-space hard line breaks. An explicit `insert_final_newline=false` rule removes terminal line breaks.

EditorConfig supports a bounded subset of patterns and properties; Latin-1 is not supported. Snippets do not support nested placeholders, choices, transformations, or executable scripts. See [editor conventions and snippets](https://github.com/namJeongwan/duckpad/blob/main/docs/editor-conventions.md) for supported syntax and limits.

## Validation

Unit and native Scintilla integration tests cover rule inheritance, indentation, save/Save As, BOM and encoding precedence, cleanup of unchanged files, external conflicts, Undo/recovery, placeholder navigation, and linked typing. Korean snippet-panel layout and persistence were checked; other locale layouts and physical Intel/macOS 13 execution were not checked. Final package, archive, and update-feed results are recorded in the published release.
