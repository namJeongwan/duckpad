# Duckpad 0.9.2

This patch fixes missing syntax colors across registered languages, including JSON, CSS, SQL, YAML, and other Lexilla lexers that do not publish named-style metadata.

- Restore syntax colors for 42 previously uncolored lexers. All 78 registered language entries are checked across light, dark, high-contrast light, and high-contrast dark palettes. Plain Text and CSV intentionally remain plain text.
- Give JSON property names, strings, numbers, and literals distinct colors. Configure JSON and YAML literal keywords, CSS properties and pseudo-selectors, Objective-C directives, and the correct PHP keyword-list index.
- Give native property, attribute, and tag styles a dedicated color, and keep lexical errors distinguishable from ordinary tokens.
- Correct Smalltalk binary-selector and Oracle SQL q-string colors. Palette and language changes preserve document contents and editing history.

App and helpers: **0.9.2 (51)**. Requires **macOS 13 or later**. Includes Apple Silicon and Intel binaries. Existing documents, session formats, workspace behavior, and the `duckpad` terminal command remain compatible.

## Installation

Download `Duckpad-0.9.2-universal.dmg`, open it, and drag Duckpad into Applications. Alternatively, extract `Duckpad-0.9.2-universal.zip`. Verify downloads against `SHA256SUMS.txt`. In-app updates become available after publication of the signed Sparkle feed.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. The Sparkle archive uses a separate Ed25519 signature.

## Validation and limitations

Native regression tests exercise 78 language fixtures and 64 distinct lexers in four palettes, plus recognized keyword tokens for the 20 declared keyword-complete entries, JSON color separation, language reset, and special Smalltalk/SQL token roles. Related editor and manifest validation passed 95 tests. A separately packaged preview was opened through the native file dialog, and JSON colors were checked in the running application. Language captures were inspected in light and dark palettes.

Representative lexical fixtures do not establish exhaustive grammar or semantic highlighting. Existing structural support tiers and shared C++ lexers remain unchanged; some languages have limited keyword vocabulary or grammar-specific styling. Physical Intel hardware and macOS 13 execution were not checked. Final source-suite, package, archive, smoke, and update-feed results are recorded in the published release.
