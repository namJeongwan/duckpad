# Duckpad 0.4.0

Format documents directly in Duckpad with **Edit → Format Document** (`Shift–Option–F`), or enable optional **Format on Save** in Preferences.

## Changes

- Add bundled offline formatting for JSON/JSONC/JSON5, JavaScript, TypeScript, YAML, HTML/Vue, CSS/SCSS/Less, Markdown/MDX, GraphQL, Handlebars, XML, and SQL.
- Configure indentation, print width, quotes, semicolons, and SQL dialect in Preferences. Format on Save is off by default.
- Preserve normal saving when automatic formatting fails. Explicit formatting commands show concise errors without dumping document contents.
- Apply formatting as one Undo action while preserving existing edit history and recovery data.
- Reduce formatting and Undo costs with UTF-8 whitespace diffing, batched styling, and efficient recovery updates. Reuse the formatter briefly, skip unchanged revisions, and load a smaller engine bundle for JSON sessions.
- Add English and Korean formatting controls.

App and plugin runtime version: **0.4.0 (10)**.

## Installation

Requires **macOS 13 or later**. The Universal app supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.4.0-universal.dmg` and drag Duckpad into Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also provided.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

## Verification and scope

71 focused tests passed, covering bundled parsers, formatting options, cancellation, stale results, save failures, encoding, Unicode selections, Undo/Redo, and recovery. Twelve Release benchmark runs across JSON, YAML, and SQL verified exact Undo restoration, recovery bytes, and formatter idempotence.

In local Release probes, the workflow JSON formatted in about 0.09–0.10 seconds after warmup. Generated 256 KiB YAML and SQL workloads took about 0.15–0.19 seconds and 0.40–0.42 seconds respectively. Content and machine conditions affect timing; these are not comparisons with other editors.

Formatting inputs are limited to 1 MiB, output to 4 MiB, with a 15-second request timeout. A timed-out or cancelled JavaScript evaluation must finish before another formatter runtime starts. Project formatter configuration and external plugins are not loaded. Python and Rust formatting are not included. Formatting-specific translations currently cover English and Korean; other locales use the English fallback. Physical Intel hardware and automated physical keyboard delivery remain unverified.
