# Duckpad 0.15.1

This patch fixes Remote SSH File connections being treated as failed when only the remote path is invalid, and corrects input-field behaviour in Replace and the remote browser.

## Fixes

- Establish the SSH host connection before opening a typed or remembered remote path. Missing folders, files entered as folders, and invalid paths show a folder-specific error while keeping the host connected, the input intact and the last usable listing available. Correct the path and use Return or Refresh to continue through the shared connection.
- Keep folder errors out of automatic reconnect retries. A server that authenticates successfully but cannot open its home directory can still open an explicitly requested accessible folder.
- Make preview and Open use the same file when selecting from a retained listing. Editing the path clears the old selection and preview, so Open uses the newly typed destination.
- Keep long Remote Path and other shared single-line inputs on one line while editing and resizing; scroll horizontally instead of wrapping. Preserve Korean composition, selection and native Undo/Redo.
- Remove the default blue focus ring from classic Find/Replace fields. Replace uses the common input component with rounded controls, neutral focus and hover feedback, while retaining the classic dialog layout.
- Localize the new folder status and error messages in all eight supported languages.

App and all three helpers: **0.15.1 (67)**, upgrading **0.15.0 (66)**. Requires **macOS 13 or later**. The universal distribution includes Apple Silicon and Intel. Existing documents, settings, recovery data, encoding handling, Undo history and the native plugin ABI remain compatible. Remote SSH File and Log Tail Viewer remain included. No new dependencies are added.

## Installation

Download `Duckpad-0.15.1-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.15.1-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Existing installations can use Check for Updates after the signed update feed is published.

## Validation and limitations

**60 distinct focused Release test functions completed**, including two opt-in loopback SSH tests. Checks cover invalid/missing/file paths, inaccessible home directories, folder-error retry policy, retained-list selection, path editing, native shell protocol quoting, SSH reuse and cancellation, input geometry, Korean composition and Undo/Redo. Native light/dark checks verify neutral focus and single-line path layout. Read-only checks against two configured servers verify that a directory error does not replace the authenticated SSH transport; the actual browser and sandboxed XPC helper also recover after correcting the path.

The final universal app and its three helpers are verified, then exercised through isolated packaged application and SSH/Tail smoke checks before publication. Native Save-panel automation is skipped. A combined presentation test run can exit before some completion markers; affected functions are rerun individually. One existing browser-reuse test still ends without its completion marker and is excluded from the count; a standalone native harness owning NSApp.run completes its bounded-preview, multiple-open and stale-navigation workflow. The cause of the test-process exit remains undiagnosed.

Remote access remains read-only and UTF-8 only, using SSH configuration, keys or an agent. Password prompts are not supported; trust new hosts in Terminal before connecting. Existing Tail size and polling limits and the documented 0.15.0 stress-performance limits remain in effect; this patch does not introduce a universal 50 ms rendering guarantee.

Intel hardware, macOS 13 runtime, physical Korean keyboard interaction and the full repository test suite are not validated. The distribution is ad-hoc signed, without Developer ID signing or Apple notarization.
