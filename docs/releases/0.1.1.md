# Duckpad 0.1.1

A stability and performance update for Duckpad.

## Fixes

- Fix a layout feedback loop that could crash the app when resizing windows with wrapped tabs.
- Reduce redundant tab and scrollbar layout updates.
- Speed up opening and editing long ASCII lines by enabling Scintilla's verified monospaced font optimization. Unicode text keeps its normal shaping behavior.

## Installation

Requires **macOS 13 or later**. The Universal DMG supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.1.1-universal.dmg` and drag Duckpad to Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also available.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

Intel execution is tested through Rosetta on an Apple Silicon Mac; physical Intel hardware testing is not included.

[Report an issue](https://github.com/namJeongwan/duckpad/issues).
