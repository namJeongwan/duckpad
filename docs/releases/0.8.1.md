# Duckpad 0.8.1

Fix editing commands in the Find and Replace window. Pasting into a focused search field now changes that field instead of the document. Cut, Copy, Select All, Undo, and Redo also follow the focused native text control. Unavailable field commands do not fall through to the document.

App and helpers: **0.8.1 (48)**. Requires **macOS 13 or later**. Distribution includes Apple Silicon and Intel binaries. Existing file formats and settings are unchanged.

## Installation

Download `Duckpad-0.8.1-universal.dmg`, open it, and drag Duckpad into Applications. The ZIP alternative is `Duckpad-0.8.1-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Users on 0.7.0 or later can update in the app once the signed Sparkle feed is published.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. Sparkle archives use a separate Ed25519 signature.

## Validation and limitations

The regression test reproduced document changes before the fix. Twelve focused tests pass after the fix, covering Find/Replace field editing, document isolation, Undo/Redo, menu validation, search interaction, and editor command availability. The field-routing tests use real AppKit panels and menu actions with an injected key-window provider.

An interactive Command-V check could not be completed because macOS would not bring the isolated test app to the foreground. Physical Intel hardware and macOS 13 execution were not checked. Final package, archive, and update-feed results are recorded in the published release.
