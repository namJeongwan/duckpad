# Duckpad 0.14.3

Open and dismiss the Workspace filter from the keyboard, with tighter sidebar spacing and faster search-result rendering.

- In the Workspace tree, Control-F toggles the filter below the header. The normal Find command does the same while the Workspace owns focus. Escape closes the filter from either its input or the tree, cancels pending searches and restores the previous tree navigation. Document and terminal Find retain their existing behavior outside the sidebar.
- Hide the filter by default and remove its reserved empty space. Align the search icon and input, tighten header and tree rows, and show search status only when there is status text.
- Preserve the sidebar width selected through the split divider across layout, window resizing and hiding/reopening the sidebar, instead of allowing control priorities to force the minimum width.
- Remove implicit folder expand/collapse animations. Measure row widths once after batch expansion/restoration, reuse immutable filename measurements and resolve loaded nodes by path components. This avoids repeated full-tree work while rendering or dismissing search results.
- Preserve Korean composition behavior when dismissing the filter, and reject search completions arriving after dismissal or a newer query.

App and helpers: **0.14.3 (65)**, upgrading **0.14.2 (64)**. Requires **macOS 13 or later**. The universal distribution supports Apple Silicon and Intel. Existing settings, recovery data, encodings, Undo history and the native plugin ABI remain compatible. No new dependencies or user-facing strings are added.

## Installation

Download `Duckpad-0.14.3-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.14.3-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Existing installations can use Check for Updates after the signed update feed is published.

## Validation and limitations

Focused Release validation passed **36 related Swift test functions** and **2 explicit performance tests**, followed by independent code review. Coverage includes contextual Find, filter toggling and Escape, cancellation and stale results, Korean marked-text dismissal, horizontal extent after navigation restoration, divider-width retention, animation suppression, filename-search progress and selection, and layout at 160, 220 and 380 points across all eight supported languages. Native app key-event checks confirmed Control-F open/close and Escape dismissal. English and Korean sidebar snapshots were inspected visually.

On one Apple M4 Pro running macOS 27.0.1, a generated fixture with 20,000 loaded files and 1,000 directories measured first filter opening at **19.5 ms**, rendering 1,000 dispersed matches at **35.0 ms** warm p95, and restoration of 50 expanded directories at **39.0 ms** warm p95. Result rendering previously took **9.26 seconds** at warm p95 on this fixture. The UI gate checks the first sample plus the nearest-rank p95 of 11 subsequent samples, equivalent to the warm maximum, against **50 ms**. Additional asynchronous `rg`-backed result application measured **35.6-44.5 ms**. These are wall-clock action/callback-to-layout/display measurements, not hardware input-to-photon guarantees.

Complete searches over the generated 20,000-file filesystem fixture took **374-412 ms**, including the existing 120 ms Workspace-filter debounce, filesystem enumeration and UI delivery. Complete directory searches are not covered by the 50 ms UI-processing claim. Tests use generated, cache-warm fixtures and retain the existing 1,000-match Workspace filter limit.

The final universal app is verified and exercised with isolated packaged smoke checks before publication. Smoke settings, workspace roots and extension directories are separated from user state, in addition to the existing isolated recovery/bookmark sessions. Native Save-panel automation is explicitly skipped by the smoke script.

The full repository suite, physical divider dragging and Korean keyboard interaction, full manual inspection in all eight languages, Intel hardware and macOS 13 runtime were not validated. The distribution is ad-hoc signed, without Developer ID signing or Apple notarization. No separately installed ripgrep, Node or Ghostty application is required.
