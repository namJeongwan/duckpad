# Duckpad 0.10.2

This patch prevents Command-W in Preferences from closing the document underneath.

- Command-W closes the active Preferences or auxiliary window before the document menu receives the shortcut, including while editing a settings field.
- Holding the close shortcut cannot dismiss the document underneath. Releasing the shortcut and pressing it again in the editor retains normal document closing.
- Control-W continues to cancel modals and sheets or close auxiliary panels without closing the underlying document.

App and helpers: **0.10.2 (54)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel. Existing documents, sessions, settings and the native plugin ABI remain compatible.

## Installation

Download `Duckpad-0.10.2-universal.dmg` and drag Duckpad into Applications, or extract `Duckpad-0.10.2-universal.zip`. Verify the downloads against `SHA256SUMS.txt`. The signed Sparkle update feed is published after the release archive is uploaded.

## Validation and limitations

37 focused regression tests cover real Preferences/main-menu event routing with and without field editing, document preservation, normal subsequent document closing, held-key handling, missed key-up recovery, modal cancellation, Korean key events, plugin behavior and settings refresh. The application build passes. Universal bundle verification and isolated smoke checks are required before publication.

The default build is ad-hoc signed, without Developer ID signing or Apple notarization. Physical Intel hardware, macOS 13, live Korean IME and manual Preferences interaction were not tested for this patch. Interactive system picker smoke checks are skipped unless explicitly enabled.
