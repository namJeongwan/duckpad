# Duckpad 0.6.4

- Reduce large-file save delays by preparing text outside the UI thread, avoiding redundant full-document validation, reusing verified SHA-256 prefixes, and updating private APFS clones before atomic replacement. Existing encoding, line-ending, external-change, and durability checks remain in place.
- Avoid redundant recovery writes when nothing changed, retain current session metadata when writes overlap, and reserve native editing space so the first few characters do not reallocate the entire document.
- Preserve leading spaces and tabs when pressing Return in plain-text notes. Korean composition followed by Return inserts a newline with one keypress and keeps indentation. Undo/Redo retains the edit group.
- Reduce the default left text padding and expose left/right padding and line spacing in settings, with the same editable number controls used for font size. New settings are localized in all eight supported languages.
- Use blue changed-line indicators and expand the line-number gutter as documents grow, preventing large line numbers from being clipped.

App and helpers: **0.6.4 (42)**. Requires **macOS 13 or later**. Universal binaries support Apple Silicon and Intel Macs.

## Install

Download `Duckpad-0.6.4-universal.dmg`, open it, and drag Duckpad into Applications. A ZIP archive and SHA-256 checksums are also provided.

This build is ad-hoc signed and **not notarized by Apple**. Physical Intel hardware and macOS 13 hardware have not been tested.

## Validation and limitations

Regression coverage includes encoding/BOM/line endings, UTF-8 edit boundaries, concurrent edits during saves, external changes with preserved timestamps, atomic-write failures, recovery ordering, Korean composition, plain-text indentation, Undo/Redo, settings persistence, and line-number sizing.

A local release preview saved a Korean/emoji append to a disposable 1.4 GiB document in 1.24 seconds through the sandboxed app. A standalone probe measured 0.70 seconds for an append and 0.77 seconds for a truncation, with full-file SHA-256 verification. These are individual measurements, not latency guarantees. Initial loading still installs the native document synchronously; the final probe observed a 4.27-second UI-thread gap. Recovery still writes full generations. Cold caches, encoding conversion, edits near the beginning, and non-APFS volumes can take longer.

Package verification and app smoke checks cover Finder opening, bookmark save/relaunch, window layout, and sandboxed extension isolation. Native save-panel UI automation is not included. Translations are checked for matching keys; every language has not been visually inspected.
