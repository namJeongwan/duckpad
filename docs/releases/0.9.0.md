# Duckpad 0.9.0

Open Duckpad directly from the terminal. The app automatically registers the `duckpad` command on its first launch after installation or an update. Open a new zsh or bash terminal window, then run:

```sh
duckpad .
duckpad test.txt
duckpad a.txt b.txt
```

Folders open in the workspace sidebar and existing files open in editor tabs. Requests go to the active window when Duckpad is already running. Spaces and leading dashes in file names are supported; quote paths containing spaces.

The command is installed in `~/.local/bin`. Duckpad preserves existing shell settings and does not replace another program's `duckpad` command. Updates refresh the launcher without duplicating its PATH entry. Other shells need `~/.local/bin` on their PATH.

App and helpers: **0.9.0 (49)**. Requires **macOS 13 or later**. Distribution includes Apple Silicon and Intel binaries. Existing document formats are unchanged.

## Installation

Download `Duckpad-0.9.0-universal.dmg`, open it, and drag Duckpad into Applications. The ZIP alternative is `Duckpad-0.9.0-universal.zip`. Verify downloads against `SHA256SUMS.txt`. Users on 0.7.0 or later can update in the app once the signed Sparkle feed is published.

The app is ad-hoc signed, not Developer ID signed or Apple notarized. Sparkle archives use a separate Ed25519 signature.

## Validation and limitations

Focused tests cover executable installation, repeated registration, update path changes, preservation of shell settings and existing commands, folder opening, and existing file batch behavior. An isolated sandboxed app opens both `duckpad .` and a file with spaces and a leading dash through the generated launcher.

Opening an already running terminal does not change that shell's PATH. Open a new terminal window after the first app launch. Custom shell startup locations and shells other than zsh/bash require their own PATH configuration. Nonexistent files are not created by the launcher. Physical Intel hardware and macOS 13 execution were not checked. Final package, archive, automatic-registration, and update-feed results are recorded in the published release.
