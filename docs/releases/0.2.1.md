# Duckpad 0.2.1

Project information and update checks are now available in Help.

- Added About Duckpad with the installed version, copyable app information, and links to GitHub, release notes, and issue reporting.
- Added GitHub release checks at launch and through Help. Available updates open the release page for manual download.
- Kept the editor title bar free of project buttons. Help ends with a non-selectable installed-version label.
- Removed the Duckpad User Guide menu item.
- Removed the remaining black background around the app icon while preserving the existing artwork.

App and plugin runtime version: **0.2.1 (6)**.
