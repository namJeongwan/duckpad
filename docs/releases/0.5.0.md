# Duckpad 0.5.0

Preview Markdown beside your document, insert dropped images, and surround selected text with matching delimiters.

## Changes

- Add built-in Markdown preview with syntax-highlighted code, tables, images, KaTeX math, and Mermaid diagrams. Rendering engines ship with the app and work offline; document HTML is sanitized.
- Open Markdown preview with **Shift–Command–V**, the tab's preview icon, or its context menu. **Control–W** and **Command–W** dismiss the open preview while keeping the document and unsaved edits. Switching to a non-Markdown tab closes the preview.
- Drop PNG, SVG, and other images onto Markdown to choose between inserting image links and opening files. Remember the choice in Preferences. Saved documents use relative paths; unsaved documents use absolute file URLs. Images are referenced, not copied.
- Preserve Markdown whitespace on save by excluding Markdown from built-in formatting. Improve native Markdown styles and fix packaged preview resource loading.
- Surround selections with matching brackets, quotes, or backticks as one Undo action while preserving the existing edit history.
- Add independent hover and pressed feedback to preview controls and tab actions, using Zed's preview and pin icons.
- Include file rename, move, trash, printing, and tab context-menu file actions introduced since 0.4.0. Improve drag-and-drop file access persistence.

App and plugin runtime version: **0.5.0 (22)**.

## Installation

Requires **macOS 13 or later**. The Universal app supports **Apple Silicon and Intel Macs**.

Open `Duckpad-0.5.0-universal.dmg` and drag Duckpad into Applications, replacing the previous app. A ZIP and `SHA256SUMS.txt` are also provided.

This release is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. After verifying the source, follow [Apple's instructions for opening an app](https://support.apple.com/en-us/102445).

## Verification and scope

Validation covers Markdown rendering and sanitization, packaged resources, image drops, selection wrapping, Undo/Redo, IME and paste boundaries, native tab actions, menu shortcuts, localization, and signed app packaging. The full serial suite ran 913 tests with one existing folder-search UI failure (`search controls unavailable`); the final Markdown regression suite passed all 8 tests, including closing during an active render. Physical Intel hardware, macOS 13 hardware, and automated physical keyboard delivery remain unverified. The new controls include English and Korean translations; other locales use the English fallback.

Local image access may require granting its containing folder through the preview's folder button. HTTP/HTTPS images may load from the network. Preview size is not artificially capped; large documents still require memory and rendering time proportional to their content. No clipboard-history plugin is included.
