# Duckpad App Icon Source

- Attribution: user-provided Duckpad artwork.
- Original read-only location used on 2026-09-02: `/Users/namjeongwan/Downloads/Duckpad_macOS_icon_set`.
- Transformation: exact existing 16, 32, 128, 256, and 512 point PNG/2x pairs were renamed to Apple's `icon_<size>x<size>[@2x].png` iconset convention. No resizing, cropping, recoloring, or generated artwork was used.
- `Duckpad.icns` was produced from `AppIcon.iconset` with macOS `iconutil -c icns`.

The Downloads originals are not part of the repository and were not modified.
